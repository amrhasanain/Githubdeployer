# GitHub deployer

![](icon.jpeg)

### A lightweight auto GitHub deployer made with the C++ programming language.
## You must have git downloaded on your PC.

## How to use?
- Download ghdeployer and add it to the PATH.
- Test it:
```bash
ghdeployer --version
```
- See the help if you want:
```bash
ghdeployer --help
```
- Use it:
```bash
ghdeployer publish --name "Your name" --email "your github email" --repo <your repo link>
```
